# MediaVerse Cinema — легальный онлайн-кинотеатр в Telegram

Это стартовый проект Telegram Mini App для каталога **лицензированных** фильмов и сериалов с HTML5-плеером, Telegram-авторизацией, серверными избранным и историей, каталогом аниме, YouTube/TikTok и разделом VPN.

## Честно о готовности
Проект является рабочим каркасом, а не готовым сервисом с фильмами: в нём нет чужих видеофайлов и не заявлены несуществующие лицензии. Чтобы показывать фильмы, добавьте видео, которыми вы владеете или на которые у вас есть права распространения, либо используйте лицензированный API/провайдера и соблюдайте его условия. Примерная запись каталога находится в `backend/catalog.example.json`.

## Возможности
- Mini App адаптивен для телефона и компьютера.
- Разделы: фильмы, сериалы, аниме, YouTube, TikTok, поиск, избранное, история, профиль, VPN.
- HTML5-плеер для разрешённых видео URL.
- FastAPI backend: каталог, профиль, избранное, история; данные SQLite.
- Проверка Telegram Web App `initData` на сервере (обязательная для production).
- Кнопка открытия Mini App в Telegram-боте на aiogram.

## Что необходимо для запуска
- Python 3.11+
- Telegram-бот, созданный через `@BotFather`
- HTTPS-домен для Mini App
- Развёрнутый backend (например, VPS) и база данных
- Законные права на видеоконтент и прямые HTTPS URL на ваши видео

## Локальный запуск
1. `python -m venv .venv`
2. Windows: `.venv\\Scripts\\activate`
3. `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN`, `WEBAPP_URL`, `API_BASE_URL`, `BOT_USERNAME`.
5. Запустите backend: `uvicorn backend.main:app --host 127.0.0.1 --port 8000`
6. В другом терминале запустите бота: `python bot.py`
7. Mini App должен быть размещён на публичном HTTPS адресе. Укажите этот адрес в `WEBAPP_URL`, а адрес API — в `API_BASE_URL`.

Для локальной демонстрации UI можно открыть `web/index.html`, но вход Telegram, серверное избранное и история будут работать только при настроенном backend и запуске внутри Telegram.

## Каталог видео
Измените `backend/catalog.json` на основе `backend/catalog.example.json`. Для каждого видео:
- `title`, `kind`, `description`, `poster` (необязательный HTTPS URL постера)
- `video_url` — HTTPS URL видеофайла, на который у вас есть права
- `license_note` — внутреннее описание источника прав

Не добавляйте в каталог ссылки на пиратские копии, обход DRM или материалы, на распространение которых у вас нет разрешения. Сторонние сайты из предыдущего списка не встроены как источники контента.

## Безопасность перед публичным запуском
- Не публикуйте `.env`, токен Telegram или секреты.
- Используйте HTTPS.
- Не отключайте проверку Telegram `initData` в production.
- Добавьте rate limits, резервное копирование, журналирование и модерацию каталога.
- Для настоящего сервиса замените SQLite на управляемую БД при необходимости.

## VPN
Mini App не может включить VPN, установить клиент или менять сетевые маршруты ОС. Раздел VPN только объясняет настройку StealthSurf отдельно на Windows/Android. Не размещайте личную ссылку подписки VPN в приложении или репозитории.
